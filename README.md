# RizalCNProject

Portal game, mod, translation Indonesia, tools, dan tutorial.

## GitHub Pages

1. Upload `index.html`, `style.css`, dan `script.js` ke repository.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Branch: `main`
5. Folder: `/ (root)`
6. Klik **Save**.
7. Tunggu GitHub Pages selesai melakukan deployment.

URL akan berbentuk:

`https://RizalCN.github.io/RizalCNProject/`

## Catatan

Data proyek di `script.js` masih contoh. Nanti bisa kita ganti dengan proyek, link download,
screenshot, versi, changelog, dan halaman detail yang sebenarnya.
