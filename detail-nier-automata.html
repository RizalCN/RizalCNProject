NieR:Automata - Indonesian Translation

Status: Selesai | Versi Mod: v1.4

Tentang Terjemahan Ini

Proyek lokalisasi bahasa Indonesia untuk NieR:Automata mencakup seluruh terjemahan dialog utama, quest sampingan, item, hingga menu antarmuka game agar pemain dapat menikmati cerita secara lebih mendalam.

Cara Pemasangan

  1. Unduh file patch terjemahan melalui tombol di bawah.
  2. Ekstrak file hasil unduhan ke folder instalasi game NieR:Automata.
  3. Jalankan game dan nikmati terjemahan bahasa Indonesia di menu pengaturan bahasa.
